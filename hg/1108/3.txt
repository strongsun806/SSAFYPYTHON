알고리즘이란?
1부터 100까지의 합을 구하는 두 가지 알고리즘의 연산복잡도 설명
그래프의 최소 비용 문제의 주요 알고리즘 (구현 X)

1) 알고리즘이란?
- 유한한 단계를 통해 문제를 해결하기 위한 절차나 방법.
- 주로 컴퓨터 용어로 쓰이며, 컴퓨터가 어떤 일을 수행하기 위한 단계적 방법을 말한다.
- 다시 말하면 어떠한 문제를 해결하기 위한 절차라고 볼 수 있음
- 1부터 100까지의 합을 구하는 두 가지 알고리즘의 예시를 보면서 알고리즘이라는 게 어떤 건지 알 수 있다.

2) 1부터 100까지의 합을 구하는 두 가지 알고리즘의 연산복잡도 설명
- 반복문을 활용한 순차적 덧셈 : 시간 복잡도 O(N)
1부터 100까지 1씩 증가시키며 순차적으로 모두 더하는 방식이다.
입력값의 크기만큼 (N만큼) 반복해서 연산해야 하므로, 데이터가 커질 수록 연산 시간도 N에 비례해서 증가한다.

- 등차수열의 합 공식을 활용한 연산 : 시간 복잡도 O(1)
N(N+1)/2 - 가우스 공식 (101을 50번 더하는 거) 공식 하나 사용하면 
한 번에 계산이 끝남
입력값이 아무리 커지더라도 덧셈, 곱셈, 나눗셈 단 3번의 연산만으로 끝나기떄문에
연산 속도가 항상 일정하고 매우 빠르다



3) 그래프의 최소 비용 문제의 주요 알고리즘 (구현X)
- 최소 신장 트리 (MST)
그래프 내의 모든 정점을 사이클 없이 가장 적은 비용으로 연결하는 알고리즘이다
크루스칼 알고리즘과 프림 알고리즘 두 개가 있음.
크루스칼 - 간선의 가중치 비용을 기준으로 오름차순 정렬한 뒤, 사이클을 형성하지 않는 선에서
간선을 순차적으로 선택한다
프림 - 임의의 시작 정점에서 출발하여 현재 연결된 정점들과 인접한 간선 중 가장 가중치가 적은 간선을 선택해서
트리를 확장해서 나간다.

- 최단 경로 
특정 정점에서 다른 정점으로 가는 가장 적은 비용의 경로를 찾는 알고리즘이다. 
다익스트라
벨만 포드
플로이드-워셜 알고리즘이 있다.

다익스트라 (Dijkstra) 알고리즘: 단일 출발점에서 다른 모든 정점까지의 최단 경로를 구합니다. (단, 가중치가 음수인 간선이 없을 때만 사용 가능)

벨만-포드 (Bellman-Ford) 알고리즘: 다익스트라와 목적은 같지만, 가중치가 음수인 간선이 포함된 그래프에서도 사용할 수 있습니다.

플로이드-워셜 (Floyd-Warshall) 알고리즘: 모든 정점에서 다른 모든 정점으로 가는 최단 경로를 한 번에 모두 구합니다.
