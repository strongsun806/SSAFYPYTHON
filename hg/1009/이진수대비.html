📌 SWEA 5185 [이진수] 문제

첫 줄에 테스트케이스 수 T가 주어집니다.
다음 줄부터 각 테스트케이스마다 N자리 16진수가 주어지면, 각 자리 수를 4자리 2진수로 변환하여 출력하는 프로그램을 작성하시오.
(단, 2진수의 앞자리 0도 반드시 4자리를 채워서 출력해야 하며, 각 테스트케이스 출력 시 #t 형식을 준수해야 합니다)

// 입출력 예시
입력:
1
4 47FE
출력:
#1 0100011111111110

💡 핵심 포인트 & 쉽게 푸는 방법

  • 16진수 1자리 = 2진수 4자리: 16진수의 각 문자는 0~15의 값을 가지며, 이는 정확히 4비트로 표현됩니다.
  • 쉬운 방법 1 (파이썬 내장함수): format(int(char, 16), '04b') 활용
  • 쉬운 방법 2 (비트 연산 / 딕셔너리): 사전(Dictionary) 매핑 또는 비트 연산자(&, >>)로 추출

추천 파이썬 풀이 코드 

# 방법 1: format 함수 활용 (추천!)
T = int(input())
for tc in range(1, T + 1):
    N, hex_str = input().split()
    ans = ""
    for char in hex_str:
        num = int(char, 16)         # 16진수 문자를 10진수 정수로 변환
        ans += format(num, '04b')   # 10진수를 4자리 2진수 문자열로 변환 (0 채움)
    
    print(f"#{tc} {ans}")

# 방법 2: 비트 연산으로 각 비트 추출하기
# (int(char, 16) >> i) & 1 을 이용해 3번 비트부터 0번 비트까지 확인
