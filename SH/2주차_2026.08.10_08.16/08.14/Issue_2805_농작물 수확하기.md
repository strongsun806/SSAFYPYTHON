## 💡 깃허브 이슈(Issue) 작성 가이드 & 템플릿

깃허브 이슈 게시판은 혼자 공부한 기록을 남기거나, 팀 프로젝트에서 문제 해결 과정을 공유하는 아주 좋은 공간입니다. 코딩 테스트(SWEA) 풀이와 어려웠던 점을 기록할 때는 "무엇을 풀었고, 어떤 에러를 만났으며, 어떻게 해결했는가"가 한눈에 보이도록 작성하는 것이 좋습니다.

---

### 📋 추천하는 이슈 작성 형식 (마크다운 템플릿)

이슈를 생성할 때 아래의 형식을 복사해서 내용만 채워 넣으시면 깔끔하게 정리됩니다.


## 📌 문제 정보
- **플랫폼:** SW Expert Academy (SWEA)
- **문제 번호/이름:** 2805번 - 농작물 수확하기
- **난이도:** D3

---

## 💻 제출 코드
```python
T = int(input())
for test_case in range(1, T + 1):
    N = int(input())
    farm = [list(map(int, input())) for _ in range(N)]

    # 농작물을 수확해 얻는 수익 초기값 세팅
    income = 0
    # 각 행과 열의 중심점 잡기
    center = N // 2

    for i in range(N):
        # 대칭인것을 이용해서 중심에서 부터 시작할 거리 계산
        distance = abs(i - center)
        # 중심에서 대칭점을 기준으로 열로 이동할 때, 계산할 시작과 끝 범위 설정
        for a in range(distance, N - distance):
            # 열로 이동할 때마다 농작물을 수확해 얻는 수익을 income 변수에 계속 더하기
            income += farm[i][a]
            
    print(f"#{test_case} {income}")

```

## 🔥 어려웠던 점 & 트러블 슈팅 (Troubleshooting)

1. **문제 상황 / 고민:**
* 이 문제는 초기 구상도 못했음 각 열에서 어떻게 마름모가 되도록 범위를 지정해야하는지 규칙성을 찾기 어려웠음
* AI의 도움으로 풀이 구상과 대칭인 점을 이용해서 중심에서부터 시작해야한다는 걸 알았지만 거리의 개념을 적용할 줄 몰랐음
* 코드는 잘 작성했다고 생각했지만 문법오류가 발생했음



2. **원인 분석:**
* 문법 오류가 발생한 부분이 농장을 리스트로 만들 때, 아래 코드로 사용
```python
farm = [list(map(int, input().split())) for _ in range(N)]
```
input을 보니까 띄어쓰기가 되어있지 않아 .split()이 있으면 안됐음



3. **해결 방법:**
* AI에게 정답을 알려주지 말고 힌트만 달라고 한 다음 힌트 흐름에 맞춰서 계속 고민함
* abs함수를 통해 절댓값을 적용해 대칭인 점을 이용해 중심으로 부터 위 혹은 아래로 이동할 때 같은 범위를 지정함
