## 💡 깃허브 이슈(Issue) 작성 가이드 & 템플릿

깃허브 이슈 게시판은 혼자 공부한 기록을 남기거나, 팀 프로젝트에서 문제 해결 과정을 공유하는 아주 좋은 공간입니다. 코딩 테스트(SWEA) 풀이와 어려웠던 점을 기록할 때는 "무엇을 풀었고, 어떤 에러를 만났으며, 어떻게 해결했는가"가 한눈에 보이도록 작성하는 것이 좋습니다.

---

### 📋 추천하는 이슈 작성 형식 (마크다운 템플릿)

이슈를 생성할 때 아래의 형식을 복사해서 내용만 채워 넣으시면 깔끔하게 정리됩니다.


## 📌 문제 정보
- **플랫폼:** SW Expert Academy (SWEA)
- **문제 번호/이름:** 4866번 - 괄호검사
- **난이도:** D2

---

## 💻 제출 코드
```python
T = int(input())

for test_case in range(1, T + 1):
    text = input()

    # 괄호만 넣을 빈 리스트 생성
    stack = []
    # 정상인 경우를 기본값으로 설정
    result = 1

    for char in text:
        # 반복문을 활용해 하나씩 확인하다가 여는 소괄호, 중괄호일 경우 stack리스트에 추가
        if char == '(' or char == '{':
            stack.append(char)

        # 만약 닫는 소괄호라면 stack리스트가 비어있거나 마지막 인덱스가 여는 소괄호가 아니라면 결과값을 0으로 변경 후 break
        elif char == ')':
            if not stack or stack[-1] != '(':
                result = 0
                break
            # 만약 닫는 소괄호라면 여는 소괄호를 stack리스트에서 제거
            stack.pop()

        # 만약 닫는 중괄호라면 stack리스트가 비어있거나 마지막 인덱스가 닫는 소괄호가 아니라면 결과값을 0으로 변경 후 break
        elif char == '}':
            if not stack or stack[-1] != '{':
                result = 0
                break
            # 만약 닫는 중괄호라면 여는 중괄호를 stack리스트에서 제거
            stack.pop()

    # pop 함수를 사용해서 제거했기 때문에 짝이 맞다면 stack리스트가 비어있어야 정상 아니라면 비정상
    if stack:
        result = 0

    print(f"#{test_case} {result}")

```

## 🔥 어려웠던 점 & 트러블 슈팅 (Troubleshooting)

1. **문제 상황 / 고민:**
* 첫 시도에서 VScode에서는 통과 됐지만, SWEA에서 Pass가 안되어 당황했음



2. **원인 분석:**
* 두개의 elif 구문에 "result = 0" 없이 했음
마지막에 stack리스트에 괄호가 남아있을 경우 "result = 0"으로 하니까 필요없다고 생각함
그런데 "result = 0"이 없으면 예시 중 닫는 괄호가 먼저 나오는 경우 if not stack에서 단축 평가가 돼서
결과값이 0이 되어야하지만 "result = 0"을 설정하지 않아 초기값인 1이 출력되는 상황이 발생함
```python
    elif char == ')':
        if not stack or stack[-1] != '(':
            break
        stack.pop()
```

3. **해결 방법:**
* 고민하다 도저히 원인을 몰라 AI의 도움을 받아 해결함

### 🚀 깃허브에 올리는 방법 (순서)

1. **저장소(Repository) 이동:** 본인의 알고리즘 공부용 깃허브 저장소로 들어갑니다.
2. **Issues 탭 클릭:** 상단 메뉴에 있는 **`Issues`** 탭을 클릭합니다.
3. **New issue 클릭:** 초록색 **`New issue`** 버튼을 누릅니다.
4. **제목 작성:** 직관적으로 알아볼 수 있게 작성합니다.
   * *예시: `[SWEA] D2 1204번 - 최빈수 구하기 풀이 및 트러블 슈팅`*
5. **내용 작성:** 위에서 제공한 템플릿을 붙여넣고 본인의 생각이나 추가하고 싶은 내용을 적습니다.
6. **라벨(Labels) 부착 (선택):** 우측 메뉴에서 `algorithm`, `python`, `trouble-shooting` 같은 라벨을 붙여주면 나중에 모아보기 편합니다.
7. **Submit new issue 클릭:** 완료 버튼을 누르면 등록됩니다!
