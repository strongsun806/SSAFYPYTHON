## 💡 깃허브 이슈(Issue) 작성 가이드 & 템플릿

깃허브 이슈 게시판은 혼자 공부한 기록을 남기거나, 팀 프로젝트에서 문제 해결 과정을 공유하는 아주 좋은 공간입니다. 코딩 테스트(SWEA) 풀이와 어려웠던 점을 기록할 때는 "무엇을 풀었고, 어떤 에러를 만났으며, 어떻게 해결했는가"가 한눈에 보이도록 작성하는 것이 좋습니다.

---

### 📋 추천하는 이슈 작성 형식 (마크다운 템플릿)

이슈를 생성할 때 아래의 형식을 복사해서 내용만 채워 넣으시면 깔끔하게 정리됩니다.


## 📌 문제 정보
- **플랫폼:** SW Expert Academy (SWEA)
- **문제 번호/이름:** 1974번 - 스도쿠 검증
- **난이도:** D2

---

## 💻 제출 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.

for test_case in range(1, T + 1):
    #test_case ->7 3 6 4 2 9 5 8 1
    matrix=[]
    #앞으로 있을 for문들에서 오류발견 시 wrong_count를 올려서 마지막에 카운드가 존재한다면,\
    #문제가 있는 매트릭스로 판단하기로 정함   
    wrong_count = 0
    #가로열 검증 - a라는 리스트에 숫자들을 넣고, set(집합)을 이용해서 중복이 없는지 판단(문제조건 = 1~9정수) 
    for i in range(1,10):#(1,2,3,4,5,6,7,8,9)
        a=list(input().split())
        matrix.append(a)
        if len(set(a)) < 9:
            wrong_count+=1
    # print(matrix)
    #세로열 검증 - matrix2에 세로열의 리스트를 만들어서 가로열과 동일하게 검증
    for i in range(9):
        matrix2=[]
        for j in range(9):
            matrix2.append(matrix[j][i])
        if len(set(matrix2)) < 9:
            wrong_count+=1
    #★★★ 어려웠던 구간 3*3 구간을 생각해내기 어려웠다.        
    for i in range(0, 9, 3):
        for j in range(0, 9, 3):
            #i와 j를 이용해서 시작점을 잡음
            matrix3 = set()
        
            #3*3을 순환
            for r in range(3):
                for c in range(3):
                    matrix3.add(matrix[i + r][j + c])
        
            #검증법은 위와 동일
            if len(matrix3) < 9:
                wrong_count += 1
    #위의 for문을 문제없이 지나왔다면, wrong_count가 0일 것.
    if wrong_count>0:
        print(f'#{test_case}', 0)
    else:
        print(f'#{test_case}', 1)

```

## 🔥 어려웠던 점 & 트러블 슈팅 (Troubleshooting)

1. **문제 상황 / 고민:**
* 문제를 풀 방법은 이 방법 뿐인가?(가로, 세로, 3*3 각자 검증)
* 가로, 세로는 조금 생각했더니 떠올랐지만, 3*3은 쉽게 떠오르지 않음
* 막상 메모리라던가 속도 좀 줄여보려고 오류를 발견하면, break로 끊고 넘어가보려고함(ex.7번 문제의 경우 가로줄에만 2번 문제점이 존재함)
* 하지만 break로 끊으니 다음 for 문으로 넘어가서 덜 읽은 7번 문제의 나머지 부분을 8번문제의 시작점으로 인식해버리는 문제가 존재했음


2. **원인 분석:**
* 3*3을 순환한다는 부분이 머리로는 이해가 가지만, 어떻게 돌게만들지 코드로 작성해내는 부분이 힘들었음
* break문제는 일단, 삭제하고 그냥 전체 순환하게 하면 문제는 없어서 break문을 빼고 작성하였지만, 다른 효율 좋은 방법이 있다면 알고 싶음.
