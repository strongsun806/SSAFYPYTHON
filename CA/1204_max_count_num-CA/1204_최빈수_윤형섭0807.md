## 💡 깃허브 이슈(Issue) 작성 가이드 & 템플릿

깃허브 이슈 게시판은 혼자 공부한 기록을 남기거나, 팀 프로젝트에서 문제 해결 과정을 공유하는 아주 좋은 공간입니다. 코딩 테스트(SWEA) 풀이와 어려웠던 점을 기록할 때는 "무엇을 풀었고, 어떤 에러를 만났으며, 어떻게 해결했는가"가 한눈에 보이도록 작성하는 것이 좋습니다.

---

### 📋 추천하는 이슈 작성 형식 (마크다운 템플릿)

이슈를 생성할 때 아래의 형식을 복사해서 내용만 채워 넣으시면 깔끔하게 정리됩니다.


## 📌 문제 정보
- **플랫폼:** SW Expert Academy (SWEA)
- **문제 번호/이름:** 1204번 - 최빈수
- **난이도:** D2

---

## 💻 제출 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.



for test_case in range(1, T + 1):
    
    line_num=int(input())
    #데이터를 정렬된 숫자들의 리스트로 만듦
    data = sorted(list(map(int, input().split())))
    # print(f"[{line_num}번째 숫자 리스트]: {data}")
    max_num_list=[]
    #점수는 1~100의 정수 범위를 가진다고 하였으니 [100점의 갯수,99점의 갯수...1점의 갯수] 이렇게 리스트 제작
    for score in range(1,101)[::-1]:#(1,2,3,....100)
        max_num_list.append(data.count(score))
    # print(max_num_list, len(max_num_list)) #[100점 10개, 99점 8개...]

    max_score = 100 - max_num_list.index(max(max_num_list))#최고점수
    print(f"#{test_case}",max_score)

```

## 🔥 어려웠던 점 & 트러블 슈팅 (Troubleshooting)

1. **문제 상황 / 고민:**
* 문제 자체는 쉬웠지만, 배운대로 for문을 쓴 알고리즘을 이용했다기 보단, map이라던가 count라던가 index라던가 메서드를 이용하려 했던것같다.
* 심지어는 잘 알지도 못하는 메서드들이여서 test.py를 만들어서 "count 메서드가 값이 없을 때 0을 반환하던가? 오류를 반환하던가?"이러한 문제점이 있었다.


2. **원인 분석:**
* 배운걸 써먹어보려고 했지만, 잘 알지도 못하는(익숙치 않은)메서드들을 써보려다가 알고리즘도, 메서드 사용법도 애매하게 배움
* for문으로 모든 것을 순환하면 괜히 속도가 느려질 것 같고, 메모리도 많이 잡아 먹을 것 같았음.


3. **해결 방법:**
* 이번 문제의 경우엔, 쉬운 문제였다고 생각해서 새로 짜보진 않고 머리로 다시 코드를 짜보려고 함.
* 인덱스는 쓴다고 치고, for 문을 순환하면서 각 점수의 차례일 때, 99점이면 list[99]=list[99]+1 이런식으로 리스트를 만드는게 더 나았겠다 싶음
