문자왔숑?

[문제]

눈을 떠 보니 2000년대 중반으로 시간 여행을 해 버렸다.

주머니에는 스마트폰 대신 작은 화면과 숫자 버튼이 달린 피처폰이 들어 있었다. 누군가에게 문자 메시지를 보내려는데, 화면을 아무리 눌러도 반응이 없다. 메시지를 작성하려면 휴대전화의 물리 버튼을 눌러야 한다!

이 휴대전화에서는 하나의 숫자 키에 여러 개의 알파벳이 배정되어 있으며, 같은 숫자 키를 연속해서 누른 횟수에 따라 입력되는 알파벳이 결정된다.

[휴대전화 자판 이미지 삽입]

각 숫자 키에 배정된 알파벳은 다음과 같다.

2 : A, B, C
3 : D, E, F
4 : G, H, I
5 : J, K, L
6 : M, N, O
7 : P, Q, R, S
8 : T, U, V
9 : W, X, Y, Z

처음에는 작성된 문자열이 비어 있으며, 커서는 빈 문자열의 시작 위치에 있다. 커서는 문자열의 맨 앞, 문자 사이 또는 맨 뒤에 위치한다.

1. 알파벳 입력

2~9번 키를 누르면 현재 커서 위치에 해당 키의 첫 번째 알파벳이 삽입된다.

같은 숫자 키를 연속해서 누르면 방금 삽입한 글자가 해당 키에 배정된 다음 알파벳으로 바뀐다. 마지막 알파벳 다음에는 다시 첫 번째 알파벳으로 돌아간다.

예를 들어 2번 키를 연속해서 누르면 다음과 같이 변한다.

A → B → C → A → B → C → …

따라서 2, 22, 222, 2222는 각각 A, B, C, A를 선택한다. 여러 번 눌러도 입력되는 글자는 한 글자이며, 숫자 키를 누르는 동안 커서는 이동하지 않는다.

하나의 알파벳을 선택하는 숫자 연타가 끝나면 반드시 바로 다음에 R을 눌러야 한다. R을 누르면 해당 알파벳의 입력이 확정되고, 커서는 방금 입력한 글자의 바로 오른쪽으로 이동한다. 마지막으로 입력하는 알파벳도 반드시 R로 확정해야 한다.

각 알파벳의 입력 예시는 다음과 같다.

2R       : A
22R      : B
222R     : C
2222R    : A
2222222R : A
7777R    : S
77777R   : P
99999R   : W

즉, 2222R과 2R은 같은 글자 A를 입력한다.

BEE는 다음과 같이 입력할 수 있다.

22R33R33R

커서가 문자열의 중간에 있을 때 알파벳을 입력하면 기존 문자를 덮어쓰지 않고 현재 커서 위치에 새로운 글자가 삽입된다.

2. 커서 이동과 R의 동작

L을 누르면 커서가 왼쪽으로 한 칸 이동한다.

R을 눌렀을 때의 동작은 다음과 같다.

- 입력 중인 알파벳이 있으면 해당 알파벳의 입력을 확정하고, 커서를 방금 입력한 글자의 바로 오른쪽으로 이동한다.
- 입력 중인 알파벳이 없고 커서 오른쪽에 문자가 있으면, 커서를 오른쪽으로 한 칸 이동한다.
- 입력 중인 알파벳이 없고 커서가 문자열의 맨 오른쪽에 있으면, 공백 한 칸을 추가하고 커서를 추가된 공백의 바로 오른쪽으로 이동한다.

알파벳을 확정하는 R은 공백을 추가하지 않는다.

예를 들어 2R의 결과는 A이며, 2RR의 결과는 A 뒤에 공백 한 칸이 붙은 문자열이다.

공백이 추가되는 경우를 제외하면 커서 이동으로 작성된 문자열은 바뀌지 않는다.

3. 공백 입력

0을 누르면 현재 커서 위치에 공백 한 칸이 삽입되고, 커서는 삽입된 공백의 바로 오른쪽으로 이동한다.

공백 입력에는 확정을 위한 R이 필요하지 않다. 0을 연속해서 누르면 누른 횟수만큼 공백이 삽입된다.

4. 문자 삭제

X를 누르면 커서 바로 왼쪽의 문자 한 개가 삭제된다. 삭제 후 커서는 삭제된 문자가 있던 위치에 놓인다.

공백도 문자 한 개로 취급하므로 X로 삭제할 수 있다.

예를 들어 AB|C에서 X를 누르면 A|C가 된다. 여기서 |는 커서 위치를 나타내며 실제 문자열에 포함되지 않는다.

[입력 과정 예시]

DAD를 만드는 다음 입력을 살펴보자.

3R3RL2222R

각 조작 이후의 문자열과 커서 위치는 다음과 같다.

처음  : |
3R    : D|
3R    : DD|
L     : D|D
2222R : DA|D

2번 키를 네 번 누르면 A가 선택된다. 두 D 사이에 A가 삽입되므로 최종 문자열은 DAD이다. 3R3RL2R로 입력해도 결과는 같다.

휴대전화에서 누른 키의 순서가 주어질 때, 모든 입력이 끝난 후 화면에 작성되어 있는 문자열을 출력하는 프로그램을 작성하라.

[입력]

첫 번째 줄에 테스트 케이스의 수 T가 주어진다.

각 테스트 케이스마다 한 줄에 누른 키의 순서를 나타내는 문자열 S가 주어진다.

[제약 사항]

1. 1 ≤ T ≤ 100이다.
2. 1 ≤ |S| ≤ 100,000이다. |S|는 문자열 S의 길이를 의미한다.
3. 모든 테스트 케이스에 대한 |S|의 합은 1,000,000 이하이다.
4. S는 숫자 0, 2~9와 영문 대문자 L, R, X로만 구성된다.
5. 하나의 알파벳은 동일한 숫자 키를 한 번 이상 연속해서 누른 뒤 R을 누르는 방식으로 입력한다. 배정된 알파벳 수보다 많이 누르면 첫 번째 알파벳부터 순환한다. 연타 횟수에는 S의 길이 제한 외에 별도의 상한이 없다.
6. 알파벳을 선택하는 숫자 연타 바로 뒤에는 반드시 R이 주어진다. R로 확정하기 전에 다른 숫자 키, 0, L 또는 X가 주어지거나 입력이 끝나는 경우는 없다.
7. L이 주어질 때에는 커서 왼쪽에 문자가 존재한다.
8. X가 주어질 때에는 커서 왼쪽에 삭제할 문자가 존재한다.
9. 각 테스트 케이스는 빈 문자열에서 시작한다.

입력 문자열의 L, R, X는 조작 명령이다. 알파벳 L, R, X 자체를 입력하려면 각각 555R, 777R, 99R을 사용할 수 있다.

[출력]

각 테스트 케이스마다 한 줄에 '#t'를 출력한 뒤 공백 한 칸을 출력하고, 최종 문자열을 출력한다. t는 1부터 시작하는 테스트 케이스 번호이다.

최종 커서 위치는 출력하지 않는다.

최종 문자열에 포함된 모든 공백은 그대로 출력한다. 문자열의 맨 앞이나 맨 뒤에 있는 공백도 제거하지 않는다.

최종 문자열이 비어 있다면 '#t'와 구분용 공백 한 칸을 출력한 뒤 줄을 바꾼다.

[입력 예시]

5
22R33R33R
3R3RL2R
55R33R33R7R4R666R444R66R4RLLLLL0
2R
2222R

[출력 예시]

#1 BEE
#2 DAD
#3 KEEP GOING
#4 A
#5 A
