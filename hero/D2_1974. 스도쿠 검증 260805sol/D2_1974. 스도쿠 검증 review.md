## 💻 제출 코드
```python
import sys
sys.stdin = open("input.txt", "r")

T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    matrix = []
    for i in range(9):
        row = []
        for j in input().split():
            row.append(j)
        matrix.append(row)

    check_set_square = set()

    # 3x3 박스 검증
    is_it_correct = 0
    for n in range(3):
        for m in range(3):
            for 행 in range(9):
                for 열 in range(9):
                    if (행 // 3 == m) and (열 // 3 == n):
                        check_set_square.add(int(matrix[행][열]))
            if check_set_square == {1, 2, 3, 4, 5, 6, 7, 8, 9}:
                is_it_correct += 1

    # 행 검증
    for k in range(9):
        check_set_row = set()
        for 행 in range(9):
            if 행 == k:
                for 열 in range(9):
                    check_set_row.add(int(matrix[행][열]))
                    
        if check_set_row == {1, 2, 3, 4, 5, 6, 7, 8, 9}:
            is_it_correct += 1

    # 열 검증
    for k in range(9):
        check_set_column = set()
        for 열 in range(9):
            if 열 == k:
                for 행 in range(9):
                    check_set_column.add(int(matrix[행][열]))
                    
        if check_set_column == {1, 2, 3, 4, 5, 6, 7, 8, 9}:
            is_it_correct += 1

    if is_it_correct == 27:
        print(f'#{test_case} 1')
    else:
        print(f'#{test_case} 0')
```

## 🔥 어려웠던 점 & 트러블 슈팅 (Troubleshooting)

1. **문제 상황 / 고민:**
* 딱봐도 행렬같아서 저번 월말평가 때 한건줄 알고 할만하다 생각했는데, 돌이켜보니까 그땐 행렬을 만드는게 아니라
  주어진 행렬을 반복문을 통해서 데이터를 만지는거였음을 알고 경악함.
  직접 행렬만드는데만 시간을 한참 쓴듯.. 


2. **원인 분석:**
* 내가 멍청했음.


3. **해결 방법:**
* 우선 크게 3가지 조건에 대한 경우로 나눴음.
  1. 3x3 정사각형
  2. 행
  3. 열
  우선 행렬을 만들고 그 행렬에 주어진 데이터를 넣었음.
  위 3가지 경우에 대해서 각각 반복문과 조건문을 사용해서 빈 set에 값들을 넣어서 비교했음.
  set의 특성 중에 중복은 제거되는 특성을 활용한 아이디어였음.
  그리고 같아야하는 set인 {1, 2, 3, 4, 5, 6, 7, 8, 9}와 비교해서 같다면 카운팅을 하나씩 해서
  스도쿠 하나 당,
    박스의 개수인 9개
    행의 개수인 9개
    열의 개수인 9개
  가 모두 카운팅 되어서 총 27이 카운팅 되었을 때만 1이 출력되고 나머지는 0이 되도록해서 구현했음.
